# Handoff T-001 — Prefetch en idle solo de rutas cuyo tab tiene el viewer

## Interfaz expuesta
- `useIdleRoutePrefetch(permissions: readonly string[]): void` en `src/app/useIdleRoutePrefetch.ts`.
  Ahora **recibe un parámetro obligatorio**: la lista de permisos del viewer. Cualquier caller nuevo
  debe pasarla (antes no tomaba argumentos).
- Comportamiento: tras el primer paint, en idle (`requestIdleCallback`, fallback `setTimeout` 1200 ms),
  dispara el dynamic import solo de las entradas de `routePrefetchers` cuyo path pasa
  `isRouteAllowed(path, permissions)` de `@/core/permissions/posTabs.ts`. Dedup por función
  (`/caja`, `/caja/abrir`, `/caja/cerrar` → un solo import). Con `permissions` vacío no precarga nada.
  Desmontar antes del idle cancela el prefetch.
- Caller único: `AppShell` en `src/app/App.tsx` pasa `viewer?.permissions ?? NO_PERMISSIONS`
  (constante de módulo, referencia estable) leyendo `viewer` de `usePosAuth()`.

## Archivos

## Decisiones tomadas
- La fuente de verdad del mapa ruta→tab→permiso sigue siendo `posTabs.ts`; el hook **no** duplica
  ninguna lista de rutas. Si se agrega un tab/ruta, basta registrarlo en `POS_TABS` + `routePrefetchers`.
- Guard explícito `permissions.length === 0 → return`: sin ningún tab el viewer ve "Sin módulos
  habilitados", así que no se precarga ni siquiera una ruta fuera de todo tab (hoy no existe ninguna
  en `routePrefetchers`, pero `isRouteAllowed` devuelve `true` para esos paths por diseño).
- `NO_PERMISSIONS` como constante de módulo en `App.tsx`: un `[]` inline sería una referencia nueva
  en cada render y, al ser dependencia del efecto, cancelaría y reprogramaría el idle en bucle —
  el prefetch nunca dispararía mientras el viewer fuera `null`.
- `router.tsx` y `routePrefetchers` quedaron intactos (alcance de la tarea).

## Advertencias para dependientes
- El hook se mockea fácil en tests con `vi.mock('./router')` + `vi.hoisted`; jsdom no tiene
  `requestIdleCallback`, así que hay que usar `vi.useFakeTimers()` + `vi.runAllTimers()` dentro de `act`.
- Si alguien agrega una ruta lazy a `routePrefetchers` que no pertenezca a ningún tab, se precargará
  para cualquier viewer con al menos un permiso (comportamiento de `isRouteAllowed`). Si esa ruta
  debe gatearse, hay que darle un tab/permiso en `POS_TABS`.
- `AppShell` ahora consume `usePosAuth()`: re-renderiza con cada cambio del contexto de auth. Es
  barato (solo renderiza `RouterProvider`), pero no meter estado caro ahí.
- `npm run lint` del repo ya estaba en rojo antes de esta tarea (errores en `src/test/mocks/repositories.ts`,
  `features/walkins/...`, etc.); los 3 archivos tocados aquí pasan eslint limpios.
