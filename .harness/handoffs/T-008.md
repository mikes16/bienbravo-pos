## Decisiones tomadas
- Orden de cesión en anchos chicos, sólo con clases (sin JS ni media queries nuevas):
  fecha `hidden md:block` → reloj `hidden sm:block` → estado `hidden min-[420px]:block`.
  El nombre nunca se oculta: `min-w-0` en toda la cadena flex + `truncate`, así que a lo
  sumo se elipsiza. Verificado que `min-[420px]:block` compila y queda después de
  `.hidden` en el CSS de dist.
- El botón de bloqueo conserva `aria-label="Bloquear sesión"` y agrega el texto visible
  `Bloquear`; el nombre accesible contiene la etiqueta visible (WCAG 2.5.3 ok).
- Área táctil de 44 px como `style` inline (no sólo clase) para que sea asertable en
  jsdom — mismo patrón que el botón Reintentar de `MoneyValue` (T-006).
- Sin status (loading) la línea dice sólo `SESIÓN ACTIVA`: no se inventa un estado.
- Esquinas rectas en el botón (el mockup dibuja 4 px de radio, pero el lenguaje visual
  del POS es sharp 0 px salvo avatares).
