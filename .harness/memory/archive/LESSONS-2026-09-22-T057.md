- [test] (x1, T-023) Un store de módulo compartido entre tests se resetea en beforeEach, nunca en afterEach: el afterEach propio corre ANTES del cleanup de Testing Library y la notificación llega a un hook aún montado (aviso 'not wrapped in act').
- [test] (x1, T-024) Una bandera que debe valer true 'mientras la mutation viaja' se publica imperativa en el try/finally, no derivada con useEffect: el efecto se agenda tras el render y una mutation rápida puede resolverse antes, dejando la publicación sin ocurrir nunca.
- [test] (x1, T-025) Al montar en el shell un componente que consulta Apollo, mockea su hook en TODOS los tests que renderizan el shell: sin mock siguen en verde pero escupen 'No more mocked responses' y arman temporizadores reales.
- [api] (x1, T-026) Antes de clasificar un error del API por extensions.code, revisa cómo lo lanza el resolver: un throw new Error() pelón pierde el código y, en producción, también el mensaje (el filtro de excepciones lo enmascara) — clasificar por texto sólo funciona en dev.
